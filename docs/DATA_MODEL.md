# Модель данных

`students`: имя, класс, баланс кредитов, отметка о рекомендации/выставлении 5.

`attempts`: studentId, moduleId, taskId, attempts, correct, help[], seconds, lastCode, testPassed, testTotal, lastError, earned.

Результаты разделены: обязательный учебный прогресс (54 задания), испытания повышенной сложности (6), самостоятельность, игровая валюта и секретный уровень.

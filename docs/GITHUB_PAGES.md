# GitHub Pages и хранение данных

GitHub Pages раздаёт только статические файлы. Поэтому `seed-db.js` является исходным снимком демонстрационных данных. При первом входе он копируется в LocalStorage браузера.

Следствия:
1. оформление и задания на GitHub Pages выглядят так же, как локально;
2. у каждого браузера собственная копия результатов;
3. ученик с другого компьютера не увидит свой прогресс автоматически;
4. учитель не получит результаты реальных учеников с их устройств в общую таблицу;
5. очистка LocalStorage удаляет локальные изменения и при следующем запуске снова появляется стартовая база.

Для реального класса рекомендуется подключить Supabase/Firebase/собственный API. Тогда авторизация и учительский доступ должны проверяться на серверной стороне.

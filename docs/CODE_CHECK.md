# Проверка программного кода

Ученик реализует функцию Python с заданной сигнатурой. Код отправляется в отдельный Web Worker, где загружается Pyodide. Код выполняется в отдельном пространстве имён и проверяется набором тестов. Часть тестов открыта, часть скрыта.

Защитные меры демонстрационной версии: запрещены import/from, open, exec/eval/compile, dunder-доступ; при превышении времени Worker уничтожается. Код не выполняется на сервере и не имеет доступа к секретным данным. Для промышленного использования необходима серверная sandbox-среда с ресурсными лимитами.

У учителя хранятся: последняя версия кода, количество попыток, число пройденных тестов, последняя ошибка, использованные виды помощи и время выполнения.

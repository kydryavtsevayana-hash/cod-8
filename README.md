# КОД-8 — сюжетная ВКР-версия 5

## Запуск
Для Python-проверки запускайте сайт через HTTP: на Windows — `start_kod8.bat`, затем `http://localhost:8080`.

## Содержимое
- 6 модулей × 10 заданий;
- 21 демонстрационный ученик уже находятся в локальной стартовой базе;
- база хранится в `seed-db.js` и `demo-database.json`, а изменения браузера — в LocalStorage;
- учитель видит попытки, помощь, код и результаты тестов;
- код доступа учителя намеренно НЕ указан в файлах и интерфейсе открытым текстом; в клиентском коде хранится только SHA-256-хеш;
- скрытая дополнительная механика не показывается ученику до завершения 54 обязательных заданий.

## GitHub Pages
Сайт полностью статический и корректно работает на GitHub Pages. Внешний вид не меняется. Стартовые 21 ученика будут загружаться каждому новому браузеру, но изменения LocalStorage не синхронизируются между компьютерами. Для общей базы класса нужен внешний backend (например Supabase/Firebase) или собственный сервер.
